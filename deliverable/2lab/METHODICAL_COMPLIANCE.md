# Проверка по методическим указаниям ЛР №2

ЛР №2 автоматизирует подготовку среды и коллективный процесс. Код предметной системы супермаркета здесь отсутствует; FastAPI-файл является только диагностической заглушкой `/api/health`.

| Требование методички | Где выполнено |
|---|---|
| Установка и настройка виртуальной машины | `VM_SETUP.md` |
| Общее системное ПО | Docker Compose, PostgreSQL, Nginx, диагностический FastAPI |
| Сценарий подготовки среды | `setup.sh` |
| Установка и применение Redmine | `redmine/docker-compose.yml`, `REDMINE.md` |
| Роли, трекеры и workflow | `REDMINE.md` |
| Постановка задач | `backlog.csv`, 15 строк задач |
| Три роли и зоны ответственности | `TEAM.md` |
| Git и модель ветвления | `GIT_WORKFLOW.md`, `verify_git.sh` |
| Системные учётные записи | `provision_users.sh` |
| Исключения Git | `.gitignore` |
| Отчёт и материалы защиты | `REPORT_LR2.docx`, свидетельства в `evidence/` |

Официальный образ Redmine содержит собственные зависимости платформы. Лабораторная не содержит программных расширений этой платформы: проект, роли, workflow и CSV настраиваются через её веб-интерфейс. Shell-сценарии оставлены для воспроизводимой настройки Linux, Compose и Git, то есть для задач автоматизации среды этой работы.

Основание: методические указания ЛР №2, общее задание на с. 7, установка и настройка Redmine на с. 21–36, роли и отчёт на с. 77–79.
