# Проверка по методическим указаниям ЛР №1

Вариант 36 на с. 47: информационная система супермаркета. В этой директории оставлены только проектные артефакты; прикладного кода нет.

| Требование методички | Где выполнено |
|---|---|
| Концепция, границы и словарь | `CONCEPT.md` |
| Конфликты интересов и дерево функций | `CONCEPT.md` |
| Бизнес-, функциональные и нефункциональные требования | `REQUIREMENTS.md` |
| Требования к UI и CRUD-матрица | `REQUIREMENTS.md` |
| Модель предметной области | `DOMAIN_MODEL.md`, объектная и ER-диаграммы |
| UML Use Case | `diagrams/01-use-case.puml` |
| BPMN процесса продажи | `diagrams/03-sale.bpmn`, дополнительное представление PlantUML |
| Диаграмма состояний | `diagrams/04-receipt-states.puml` |
| Архитектура и структуры размещения, реализации, распределения функций | `ARCHITECTURE.md`, deployment-диаграмма |
| Три роли коллективной работы | `ARCHITECTURE.md`, `DEFENSE.md` |
| Отчёт: титул, задание, оглавление, описание, выводы, источники | `REPORT_LR1.docx` |

Четыре диаграммы, прямо запрошенные в задании, присутствуют в исходниках PlantUML. ER и deployment добавлены для полноты модели. План файлов в архитектуре описывает будущую ЛР №3 и не является выдачей её реализации.

Основание: методические указания ЛР №1, требования к отчёту на с. 3, задание и состав результатов на с. 7, вариант на с. 47.

Для BPMN графику сверяли именно с рис. 9 на с. 26 методички: события-круги, задачи, исключающие шлюзы-ромбы, пул и дорожки, потоки управления. Канонический `.bpmn` содержит те же обозначения и переходы; PlantUML-файл оставлен как читаемое текстовое представление. Список прочих стандартов и официальной документации вынесен в `SOURCES.md`.
