# Проверка по методическим указаниям ЛР №4

ЛР №4 индивидуальная, исполнитель — Кочетков Роман. Вариант 12 на с. 18 требует на основе `find` реализовать создание, объединение, удаление, редактирование файлов, включая расширения, и справку `usage`.

| Требование методички | Где выполнено |
|---|---|
| Утилита на Bash | `docforge` |
| Использование `find` и аналогов | функции поиска в `docforge` |
| Создание файлов | команда `create` |
| Объединение файлов | команда `merge` |
| Удаление | обратимая команда `delete` и `restore` |
| Редактирование текста | команда `replace` |
| Работа с именами и расширениями | команды `rename`, `extension` |
| Справочная информация | `usage`, `--help` |
| Установка в `/usr/local/bin` без `.sh` | `install.sh`, имя `docforge` |
| Назначение, зависимости, функции, расширенная справка, исходный код | `REPORT.md`, `REPORT_LR4.docx` |
| Проверка сценария | `tests/test_docforge.sh`, `evidence/` |

Shell здесь обязателен по формулировке задания. Файл `install.sh` выполняет требуемое размещение утилиты; расширение `.sh` сохраняется только у установочного и тестового сценариев, а финальная пользовательская команда называется `docforge`.

Основание: методические указания ЛР №4, задание на Bash на с. 15, вариант 12 на с. 18, требования к отчёту на с. 20.
