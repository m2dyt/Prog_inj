Использование: netconfig [ОПЦИИ] КОМАНДА [АРГУМЕНТЫ...]

Утилита конфигурирования сетевых настроек ОС Linux (ЛР №4, вариант 6).
Позволяет управлять адресацией сетевых интерфейсов через /etc/network/interfaces,
создавать статические маршруты (персистентные при перезагрузке),
настраивать сетевые мосты (bridge), а также включать и отключать интерфейсы и мосты.

Доступные команды:
  show [--config FILE]
      Отобразить сконфигурированные интерфейсы, маршруты и мосты.

  set-iface IFACE (--ip IP/MASK | --ip IP --netmask MASK | --dhcp | --manual) [--gateway GW] [--no-auto]
      Задать сетевую адресацию (IP, маска, шлюз) для интерфейса IFACE.

  add-route IFACE --network NET/PREFIX --via GW
      Добавить персистентный статический маршрут через интерфейс IFACE.

  del-route IFACE --network NET/PREFIX
      Удалить статический маршрут из конфигурации интерфейса IFACE.

  create-bridge BRIDGE --ports IFACE1[,IFACE2...] [ПАРАМЕТРЫ_IP] [--stp on|off] [--fd SEC]
      Создать сетевой мост BRIDGE и привязать к нему сетевые интерфейсы.

  del-iface IFACE
      Удалить конфигурацию интерфейса или моста из файла настроек.

  up IFACE
      Включить сетевой интерфейс или сетевой мост (ifup / ip link set up).

  down IFACE
      Отключить сетевой интерфейс или сетевой мост (ifdown / ip link set down).

  validate [--config FILE]
      Проверить синтаксическую корректность конфигурационного файла.

Общие опции:
  -c, --config FILE   Использовать альтернативный файл конфигурации (по умолчанию: /etc/network/interfaces)
  -d, --dry-run       Режим предпросмотра: валидация без фактической записи на диск и применения
  -a, --apply         Применить изменения «на лету» в ядре Linux после записи в файл (требует root)
  -v, --verbose       Вывод расширенной отладочной информации (set -x)
  --no-color          Отключить цветной вывод в терминале
  -h, --help          Показать эту справку и выйти
  --version           Показать версию утилиты

Примеры использования:
  netconfig set-iface eth0 --ip 192.168.1.50 --netmask 255.255.255.0 --gateway 192.168.1.1
  netconfig set-iface eth1 --ip 10.0.0.5/24
  netconfig add-route eth0 --network 172.16.0.0/16 --via 192.168.1.254
  netconfig create-bridge br0 --ports eth1,eth2 --ip 192.168.100.1/24 --stp off
  netconfig up eth0
  netconfig down br0
  netconfig show
