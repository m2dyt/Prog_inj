В рамках работы разработана консольная системная утилита **`netconfig`** на сценарном языке Bash. Утилита стандартизирует и автоматизирует процессы управления сетевой конфигурацией в операционных системах семейства Linux (Debian, Ubuntu и др.), осуществляя прямое управление файлом `/etc/network/interfaces`, персистентными маршрутами, сетевыми мостами и состоянием сетевых устройств ядра.

---

## 1. Системные требования и зависимости

* Операционная система: Linux (Ubuntu 20.04+, Debian 11+ или среда WSL2 Ubuntu).
* Оболочка: `bash` версии 4.4 или выше.
* Системные утилиты: `iproute2` (`ip`), `ifupdown` (`ifup`, `ifdown`), `gawk` (`awk`), `coreutils` (`mktemp`, `cp`, `chmod`, `install`, `stat`, `date`), `bridge-utils` (опционально для старых ядер).

Установка необходимых пакетов в Linux / WSL:
```bash
sudo apt update
sudo apt install -y bash coreutils gawk iproute2 ifupdown bridge-utils
```

## 2. Установка и размещение утилиты

В соответствии с требованиями методических указаний (с. 15), финальная версия утилиты размещается в системном каталоге `/usr/local/bin` под именем **`netconfig`** (без расширения `.sh`) с правами `0755`.

### Быстрая установка через скрипт `install.sh`:
```bash
sudo bash install.sh
```

После установки команда `netconfig` доступна глобально из любой директории:
```bash
netconfig --version
netconfig --help
```

Для локального запуска или тестирования без установки утилиту можно вызывать напрямую:
```bash
bash ./netconfig --help
```

## 3. Команды и примеры использования

### 3.1. Задание адресации, маски и шлюза на интерфейс (`set-iface`)
Утилита поддерживает указание параметров как раздельно (IP и маска), так и в компактной CIDR-нотации:

* Настройка со стандартной маской и шлюзом:
  ```bash
  sudo netconfig set-iface eth0 --ip 192.168.1.50 --netmask 255.255.255.0 --gateway 192.168.1.1
  ```
* Настройка через CIDR-нотацию (маска вычисляется автоматически):
  ```bash
  sudo netconfig set-iface eth1 --ip 10.0.5.100/24
  ```
* Настройка интерфейса в режиме DHCP:
  ```bash
  sudo netconfig set-iface eth2 --dhcp
  ```

### 3.2. Задание статических персистентных маршрутов (`add-route`, `del-route`)
Методические указания требуют, чтобы маршруты сохраняли работоспособность после перезагрузки машины. В `/etc/network/interfaces` они фиксируются внутри строфы соответствующего интерфейса в виде директив `up` и `down`:
* Добавление статического маршрута к сети:
  ```bash
  sudo netconfig add-route eth0 --network 172.16.0.0/16 --via 192.168.1.254
  ```
* Удаление статического маршрута:
  ```bash
  sudo netconfig del-route eth0 --network 172.16.0.0/16
  ```

### 3.3. Создание сетевого моста (`create-bridge`, `del-bridge`)
Объединяет сетевые интерфейсы в единый коммутируемый мост (Bridge):
* Создание сетевого моста `br0` с подчиненными портами `eth1` и `eth2`:
  ```bash
  sudo netconfig create-bridge br0 --ports eth1,eth2 --ip 192.168.100.1/24 --stp off --fd 0
  ```
* Удаление конфигурации сетевого моста:
  ```bash
  sudo netconfig del-bridge br0
  ```

### 3.4. Включение и отключение интерфейсов и мостов (`up`, `down`)
Утилита взаимодействует с подсистемами `ifupdown` и `ip link`:
* Включение интерфейса или моста:
  ```bash
  sudo netconfig up eth0
  sudo netconfig up br0
  ```
* Отключение интерфейса или моста:
  ```bash
  sudo netconfig down eth0
  sudo netconfig down br0
  ```

### 3.5. Просмотр и валидация конфигурации (`show`, `validate`)
* Просмотр всех сконфигурированных интерфейсов и текущего состояния ядра:
  ```bash
  netconfig show
  ```
* Проверка синтаксической корректности файла конфигурации:
  ```bash
  netconfig validate
  ```

## 4. Дополнительные инженерные опции

| Опция | Описание |
|---|---|
| `-c, --config FILE` | Указать альтернативный путь к файлу конфигурации (по умолчанию `/etc/network/interfaces`). Позволяет безопасно тестировать утилиту без прав root и риска нарушения сетевых настроек хоста |
| `-d, --dry-run` | Режим предпросмотра: валидация параметров и отображение планируемых изменений без фактической записи на диск |
| `-a, --apply` | Немедленно применить конфигурацию «на лету» в ядре Linux после успешной записи в файл |
| `--no-color` | Отключить цветное выделение вывода в терминале |
| `-v, --verbose` | Включить режим расширенной отладки `set -x` |
| `-h, --help` | Вывести полную справочную информацию (`usage()`) |
| `--version` | Вывести сведения о версии и авторе |
